# AI Video Pipeline

本地 ComfyUI 上的 AI 视频生产管线：从静态人物图出发，产出**数字人唱歌/口播视频**与**音乐 MV**。

> 全部在单机 RTX 5070 Ti（16 GB 显存）/ 31 GB 内存上跑通，无云服务。

---

## 这是什么

一条可复现的本地管线，解决三个实际问题：

1. **让一张照片开口说话/唱歌，口型对得上** —— 不是对口型（不用原唱驱动），是模型自己生成音频与口型
2. **长视频的分段生成与无缝续接** —— 10 秒是单段上限，3 分钟的片子必须切成 20+ 段，且不能出现接缝与漂移
3. **生成质量自动把关** —— 每段生成后自动转写校验，防止模型改词、漏词、自编内容

## 核心组件

| 环节 | 工具 |
|---|---|
| 图像生成 / 人物参考 | SDXL + LoRA、Qwen-Image、Z-Image |
| 视频生成（含音频） | **MiniMax H3**（T8 插件，joint AV 生成） |
| 运动控制 | Wan2.2（蒸馏 LoRA，8 步） |
| 语音转写 / 质检 | faster-whisper（CPU int8） |
| 音频分离 | Demucs |
| 后期 | ffmpeg（抽帧、拼接、色彩校准） |
| 编排 | Python（ComfyUI HTTP API） |

## 三个关键工程决策

### 1. 音频必须由视频模型自己生成，不能后期配

**做过的错事**：先用 TTS 出音频，再用 LatentSync / Wan-S2V / LongCat 做口型同步。

**全都失败了**：

- **LatentSync**：能对，但慢（一段 10 秒要十几分钟），且画质损失明显
- **Wan2.2-S2V**：语音专用模型，中文 wav2vec2 与它训练时的特征空间不匹配，**每个字都错**
- **LongCat-Video-Avatar**：训练集是音乐视频，实际跑出来口型仍然不准

**正确答案**：MiniMax H3 的 `<d>` 标签让模型**同时生成音频与视频**，口型天然对齐，因为它本来就是一起出的。

### 2. 长视频必须分段生成，但不能靠"末帧续接"硬链

这是本项目最重要的发现，详见 [`docs/pitfalls.md`](docs/pitfalls.md#1-链式漂移25-段之后画面会崩)。

**一句话**：每段用上一段的末帧做首帧，误差会**逐段放大**，20 段之后画面彻底崩坏（亮度从 147 掉到 48，脸型变形）。

**正确做法**：同时给「上一段末帧」和「原始参考图」两个约束，让模型在连贯与稳定之间拉扯。

### 3. 生成质量必须自动校验，不能人工听

模型会**自己往后编内容**（词数不够时）或**改词**。

**做法**：每段生成后用 faster-whisper 转写，与台词做**拼音级相似度**比对（不是字符级，因为 whisper 会输出繁体与同音错字）。

- 相似度 ≥ 0.85 → 通过
- < 0.85 → 换种子重跑
- 重试 3 次仍失败 → 降级使用并记录

## 快速开始

```bash
# 1. 准备 ComfyUI + T8 插件（MiniMax H3）
#    模型：minimax_h3_ref2va_pruned_int8_convrot.safetensors
#          qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors
#          minimax_h3_video_vae_int8_convrot.safetensors
#          minimax_h3_audio_vae_fp32.safetensors

# 2. 切分（需要 LRC 歌词文件）
python scripts/plan.py --lrc song.lrc --max-seconds 10.83

# 3. 逐段生成（读取 plan.json，自动起 ComfyUI 任务 + 校验）
python scripts/gen.py --plan plan.json --first-frame face.png

# 4. 看门狗（等成片出现后收尾）
python scripts/watchdog.py
```

## 已知限制

- **唱歌口型不如说话**：H3 的音色与口型按说话训练，唱歌时高音区嘴型会松
- **语速不可控**：没有语速参数，只能靠调整台词字数（10.8 秒 ≈ 40 个汉字）
- **间奏段会"念水印"**：模型偶尔发出训练数据里的视频水印语音（"字幕by…"），只能用静帧兜底
- **不能控制旋律**：给歌词它能唱，但旋律是它自己编的
